# bfgen

8-dot/6-dot braille fonts generator

概要

これはユニコード点字フォントTTFファイルを出力する[Node.js](https://nodejs.org/ja)を使ったCLIアプリケーションです。
具体的には、yamlフォーマットで書かれたフォントのデータを元にsvgデータを作成し、その内容を[svg2ttf](https://github.com/fontello/svg2ttf#readme)に渡して、TTF（TruType）ファイルを作成しています。なお、このとき生成先に同じ名前のファイルがあるときはベース名に(2),(3)という風に番号を付けた名前にします。
 -x オプションを追加すると、SVGファイルも出力します。

通常の点字フォントでは、点の無い場所がただの空白になりますが、これに形を与え、点の配置を視認しやすくしています。
この空白の点の形を、空白(empty)、空線(dash)、輪郭(outline)、空点(pin)と4種類用意しています。

点の形をSVGの書式で設定しているので、丸以外のものも作ることができます。応用として四角(square)、菱形(diamond)を用意しました。
これらのフォントは square.yaml, diamond.yaml などを使うと作れます。このときファイルでは空白の点は輪郭で描いています。
なお、codexを使えばshapeフォルダのファイル、configフォルダのファイルを新たに自動生成できることを確認しています。

図形の形を微調整したいときは、config.yaml内の定数の値を変えます。
形自体を変えたいときは、src/shapes/shape.tsで定義されているshapeクラスを継承してメソッドを記述し、src/shapesフォルダに配置します。
詳しくは[SVG](https://triple-underscore.github.io/SVG11/index.html)を調べてください。特に[20.8 フォント記述](https://triple-underscore.github.io/SVG11/fonts.html#FontDescriptions)、[8.3 パスデータ](https://triple-underscore.github.io/SVG11/paths.html#PathData)が重要です。

## 使い方

bfgen -h で次のヘルプが出力されます。

```sh
使い方: bfgen [options]

オプション:
  -v, --version   バージョン番号を出力する                              [論理値]
  -h, --help      コマンドのヘルプを表示する                            [論理値]
  -c, --config    YAML形式の設定ファイル名                             [文字列]
  -f, --fontfile  出力フォント名                                      [文字列]
  -l, --list      <config> ディレクトリにある設定ファイルの一覧を表示する
　　　　　　　　　　　　　　　　　　　　　　　　　　　　 [論理値] [デフォルト: false]
  -s, --shapes    利用可能な形状の一覧を表示する    [論理値] [デフォルト: false]
  -x, --svgxml    SVGXMLファイルも出力する        [論理値] [デフォルト: false]
```

引数無しのコマンド単独では、省略時の設定ファイル"config.yaml"、それが見つからなければプログラム内の規定値に従って、フォントを作成します（黒点は丸、白点は空線、点の数は８点）。

```sh
bfgen
```

次のコマンドで利用可能な設定ファイルのリストを閲覧します。

```sh
bfgen -l
```

そこに出てきたyamlファイル名を拡張子も含めて、-c の後に書いて実行すると点字ファイルが生成されます。

```sh
bfgen -c <configファイル名>
```

例えば、空丸付きの六点点字フォントを作りたいときは、次のようにします。

```sh
bfgen -c outline.yaml
```

なお、設定ファイル名を指定したときに、カレントフォルダに指定のファイルがあればそれ優先して使います。
つまり、プリセットの設定ファイルをカレントフォルダにコピーして、それをエディタで開き、数値等を変更することで、フォントを微調整することもできます。

## インストール

ソースから実行する場合は、`npm install` 後に `npm run build` でビルドし、
`node dist/index.js -h` で起動できます。ソース変更後も `npm run build` を実行してください。

TypeScriptのソースは`src/`に配置し、ビルドしたJavaScript・型定義・ソースマップは、ディレクトリ構造を保って`dist/`に出力します。
設定ファイルの`config/`と翻訳ファイルの`locales/`は、プロジェクト直下に配置します。

[Node.js](https://nodejs.org/ja)をコンピュータにインストールしたあと、コマンドラインから次のコマンドを実行すると、bfgenコマンドを実行できるようになります。
（npm 12.2.3 で確認済み）※必要に応じて管理者権限で

```js
npm install -g --allow-git=all https://github.com/rosmarinus/bfgen3
```

## 用語等

六点点字（6-dot braille） コンピュータで表示されるUnicode点字は、左右4点ずつの最大8つの点まで表現できます。通常使う6点の点字を表すときは、その最下段の2点を空白のままにして、上の6点部分だけを使うことになります。 このプログラムでは点の無い部分に別の印を表示しますが、六点点字として扱うときは最下段の2点は常に空白のままになります。 名前に"6"のあるプリセット設定ファイルで作成できます。設定ファイルで「sixDot: true」にすると有効になります。

八点点字（8-dot braille） 左右4点ずつの最大8つの点を使う点字です。通常の六点点字に2つの点を下に追加します。 日本では漢点字を表すために八点点字が利用されますが、その場合は追加の点は上に付きます。このプログラムでは、特に漢点字と明示しない限り、八点点字は追加の2点を下に付ける一般的な配置とします。

漢点字（kantenji braille） 川上泰一氏が考案した8点点字を使って漢字を表す点字です。漢点字は1マスから3マスを使い、一つの漢字を表します。最上段の二点で1漢字を表すマスの範囲を示し、下の六点で構成要素を表します。 名前に"-k"のあるプリセット設定ファイルで作成できます。設定ファイルで「kantenji: true」にすると有効になります。

シフト六点点字（shifted 6-dot braille） 通常の六点点字と違い、下の6点だけを使って表す6点点字を、通常のものと区別するために便宜上このように呼ぶことにします。 下に一段下げたこの六点点字は、漢点字と仮名点字を一緒に表示するときに自動的に使います。このプログラムでの漢点字と普通の八点点字の違いは実質自動的にこれが使われるかの違いになります。
